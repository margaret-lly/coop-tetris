# 部署步骤（照做即可）

代码已经改好，不需要再动任何源文件。下面只有两步：传 GitHub → Render 上线。

---

## 准备：本地先确认能跑

在项目根目录（有 `server.js`、`package.json` 的这一层）打开命令行：

```bash
npm install
npm start
```

浏览器开 `http://localhost:3000/`，能建房、能玩，就说明代码没问题。

---

## 第一步：传到 GitHub

1. 打开 https://github.com/new ，仓库名随意（如 `coop-tetris`），选 **Public**，**不要**勾选 Add a README / .gitignore / license。
2. 回到项目根目录的命令行，逐行执行（把最后一行换成你自己的用户名和仓库名）：

```bash
git init
git add .
git commit -m "init coop tetris"
git branch -M main
git remote add origin https://github.com/你的用户名/你的仓库名.git
git push -u origin main
```

如果提示要登录：用浏览器弹窗登录 GitHub 即可；或者改用 GitHub Desktop 图形界面，把整个文件夹拖进去发布。

3. 传完后打开仓库页面，确认能看到 `server.js`、`package.json`、`client/` 文件夹。

> `node_modules` 已被 `.gitignore` 排除，不会上传，属正常。

---

## 第二步：Render 上线

1. 打开 https://render.com ，用 GitHub 账号登录。
2. 右上角 **New +** → **Web Service**。
3. 选择你刚建的那个仓库（首次需要授权 Render 访问 GitHub）。
4. 配置照抄：

| 字段 | 填什么 |
|---|---|
| Name | `coop-tetris`（随意） |
| Region | `Frankfurt`（欧洲，离你近） |
| Branch | `main` |
| Root Directory | 留空 |
| Runtime | `Node` |
| Build Command | `npm install` |
| Start Command | `npm start` |
| Instance Type / Plan | `Free` |

5. 点 **Create Web Service**，等日志出现 `🚀 Co-op Tetris 运行中` 就是成功。
6. 页面顶部会给你一个地址：`https://xxx.onrender.com`，这就是最终链接。

---

## 第三步：测试

1. 自己先打开这个地址，建房 → 玩一轮，确认方块会自动下落、落到底换人。
2. 平板 / 同学直接浏览器打开同一地址，输入房间码加入。
3. 免费实例 15 分钟没人访问会休眠，第一次打开要等 30–60 秒。**到学校先自己打开链接唤醒，再叫同学进来。**

---

## 常见问题

| 现象 | 原因与解决 |
|---|---|
| 打开一直转圈 | 实例在休眠唤醒中，等 30–60 秒；超过 2 分钟仍未出来，去 Render 面板看日志是否报错 |
| 页面能开，进不去房间 | 校园网拦 WebSocket，改用平板手机热点测试 |
| Render 日志报 `Cannot find module 'express'` | 仓库里缺 `package.json` 或 `package-lock.json` 没上传，检查仓库根目录 |
| 日志报端口错误 | 不用管，代码已写 `process.env.PORT || 3000`，跟随平台分配 |
| 改完样式线上没变化 | Render 会自动重新部署，等它跑完；或手动点 Manual Deploy → Deploy latest commit |
| 想换角色图 | 覆盖 `client/assets/` 里的同名文件，推到 GitHub，自动生效 |

---

## 以后怎么更新

改完本地文件后：

```bash
git add .
git commit -m "update"
git push
```

Render 检测到 main 分支有新提交会自动重新部署，几十秒后线上就是新版。
